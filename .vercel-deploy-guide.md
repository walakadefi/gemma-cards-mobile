# GEMMA CARDS - VERCEL DEPLOY GUIDE

## Why Vercel?
- Free tier for open-source projects or personal accounts  
- Automatic builds on every git push  
- Handles large images, hot reload, no server-side code needed  
- Easy GitHub integration  

---

## QUICK SETUP (5 minutes)

### Step 1: Create free Vercel account
Go to https://vercel.com/signup and sign up with GitHub.

### Step 2: Connect your project repo
In Vercel Dashboard > New Project > Import Project > "Select from Git"

- Choose your Gemma app repository (create GitHub repo if needed)
- Build settings leave defaults (Framework preset for Next.js/React works)
- **Build command:** `npm run build` and `npx expo export --platform=web` OR skip this if building manually
- Publish directory: `app/web-build` or `.expo/public`

### Step 3: Deploy preview URL
Vercel will generate a URL like: https://gemma-cards-mobile.vercel.app

Your existing Expo link: https://gemma-cards-mobile.expo.app still works too. You can keep both or delete the older one!

## ALTERNATIVE: MANUAL UPLOAD WITHOUT REPO (if no GitHub)

### Option A: ZIP and drag-drop into Vercel
1) Run this locally in PowerShell:
```powershell
cd "C:/Users/mikae/Documents/ChatGPT/Gemma"
npx expo export --platform=web > .expo/public
Compress-Archive -Path app/web-build/* -DestinationPath Gemma-web.zip
```

2) Go to https://vercel.com/new  
3) Drag-drop the `Gemma-web.zip` file into Vercel's upload dialog ("No repo? Upload manually")  
4) Click "New Project" and it instantly generates a URL

---

### Option B: Direct GitHub Pages (free, no account needed)
1) Create a simple web app with index.html in project root folder
2) Push to public GitHub repo
3) Enable Pages at Settings > Pages in that repo  
4) Instant live site at https://yourname.github.io/gemma-cards-mobile/
