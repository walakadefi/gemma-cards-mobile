# Gemma Native Foundation Plan

**Goal:** Make the shared Expo app explicitly ready for iOS and Android packaging.

1. Add native configuration tests for identifiers, versions, assets, orientation, tablet support, and permissions.
2. Add production app icon, adaptive icon, splash asset, platform identifiers, and initial build numbers.
3. Add EAS development, preview, and production profiles without credentials or remote builds.
4. Validate resolved Expo config, tests, types, lint, web export, and clean Android/iOS prebuild generation.

This slice does not enroll developer accounts, create signing credentials, submit stores, or add sensitive device permissions.
