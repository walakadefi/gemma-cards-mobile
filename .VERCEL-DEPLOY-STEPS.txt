## 📌 TROUBLESHOOTING

### "Authentication Required" Errors:
- Generate PAT token at github.com/settings/tokens → paste in terminal when asked for password
- Or use `git credential manager cache` helper (see earlier guide)

### "Build Fails" Errors:
- Verify you pushed entire codebase including images, fonts, assets  
- GitHub will show build errors in CI/CD logs (go to repo > Actions tab)
